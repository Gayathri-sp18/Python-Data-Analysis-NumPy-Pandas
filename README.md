## 📌 About the Project

This repository contains practical Python exercises focused on **numerical computing and data manipulation using NumPy and Pandas**.

The notebook demonstrates how to create and manipulate NumPy arrays, work with Pandas Series, explore DataFrames, filter records, calculate summary statistics, group data, and modify tabular datasets.

The exercises use sample datasets such as weekly temperatures, student marks, and sales transactions to demonstrate fundamental data analysis techniques.

---

## 🎯 Topics Covered

### 🔢 NumPy Array Operations

The notebook covers:

- Importing NumPy using `import numpy as np`
- Creating one-dimensional NumPy arrays
- Creating two-dimensional NumPy arrays
- Inspecting array properties using `shape`, `dtype`, and `size`
- Performing element-wise arithmetic operations
- Converting temperatures from Celsius to Fahrenheit
- Calculating maximum, minimum, and mean values
- Accessing array elements using indexing
- Extracting data using array slicing
- Accessing selected values from two-dimensional arrays

### 📚 Pandas Series

Practical examples demonstrate:

- Creating a Pandas Series
- Assigning custom index labels
- Accessing values using `iloc` and `loc`
- Selecting individual elements and multiple records
- Filtering values based on conditions
- Updating existing Series values
- Removing elements using `drop()`
- Performing arithmetic operations on Series

### 📊 Pandas DataFrame

The notebook demonstrates:

- Creating a DataFrame using a Python dictionary
- Organizing transaction data into rows and columns
- Displaying the complete DataFrame
- Exploring records using `head()` and `tail()`
- Inspecting DataFrame dimensions using `shape`
- Accessing column names using `columns`
- Examining data types using `dtypes`
- Understanding DataFrame information using `info()`
- Selecting specific columns
- Accessing data using `iloc`

### 🔍 Data Filtering and Exploration

The exercises cover:

- Filtering transactions by region
- Applying multiple conditions using `&`
- Selecting transactions with amounts greater than a specified value
- Counting product categories using `value_counts()`
- Identifying distinct regions using `unique()`
- Grouping transactions by region
- Calculating average transaction amounts using `groupby()` and `mean()`

### ✏️ DataFrame Manipulation

The notebook demonstrates:

- Updating a transaction amount using `loc`
- Selecting a specific transaction by its ID
- Creating a new `Discount` column
- Calculating a discount equal to 10% of the transaction amount
- Removing a transaction using a filtering condition
- Dropping a column using `drop(columns=...)`
